# AnixApp

> [!WARNING]
> Проект находится в бета-тестировании. Возможны ошибки и нестабильная работа.

> [!WARNING]
> Для авторизации у вас должен быть аккаунт Anixart.

**Десктопный клиент для просмотра аниме на базе платформы Anixart.**

---

## Возможности

### Контент и навигация

- **Главная** — лента аниме: Последние, Онгоинги, Анонсы, Завершённые, Фильмы
- **Страница релиза** — описание, рейтинг, жанры, скриншоты, комментарии, похожие тайтлы
- **Закладки** — личные списки: Смотрю, Запланировано, Просмотрено, Отложено, Брошено
- **Профиль** — статистика, динамика активности, друзья, список аниме (свой и чужой)
- **Поиск** — по релизам, профилям и коллекциям с историей запросов
- **Поиск по коллекциям** — тематические подборки
- **Уведомления** — все уведомления аккаунта в одном месте

### Видеоплеер

- Потоковое воспроизведение через **HLS**
- Поддержка нескольких источников: Kodik, Sibnet, Collaps, Anilibria и другие
- Выбор озвучки и эпизода прямо в плеере
- Переход к следующему эпизоду с автоподбором альтернативной озвучки при необходимости
- Полноэкранный режим и Picture-in-Picture

### Загрузки

- Скачивание серий из плеера (HLS и прямые ссылки)
- **Быстрая параллельная загрузка HLS** для источников Kodik, Anilibria, Sibnet, Collaps и др.
- Очередь загрузок, библиотека скачанных файлов, воспроизведение с диска
- Проверка наличия **FFmpeg** и установка portable-сборки (для сборки сегментов в MP4)

Реализация быстрой HLS-загрузки вдохновлена проектом
[Kodik-Download-Watch](https://github.com/YaNesyTortiK/Kodik-Download-Watch)
(YaNesyTortiK): параллельная загрузка сегментов манифеста и склейка через `ffmpeg -c copy`.

### Апскейлинг видео Anime4K

- Улучшение качества картинки в реальном времени через **WebGPU**
- 20 режимов: готовые пресеты (ModeA/B/C и комбинации)
- Проверка доступности GPU перед включением

### Совместный просмотр (БЕТА)

- В разработке

### Discord Rich Presence (БЕТА)

- Отображение статуса: просматривает меню, смотрит аниме, открыл профиль
- Обложка релиза или аватар профиля в карточке
- Прогресс просмотра эпизода (временная шкала)
- Интеграция с лобби: приглашение по Discord, количество участников

### Темы оформления (БЕТА)

- Встроенные темы: **Авто** (по системной), **Тёмная**, **Светлая**, **AMOLED**
- Редактор кастомных тем: 8 цветовых переменных и шрифт
- Предпросмотр в реальном времени
- Сохранение, редактирование и удаление пользовательских тем
