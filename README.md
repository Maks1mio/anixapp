# AnixApp Beta

Быстрый десктоп-клиент для просмотра аниме на базе [AnixartJS](https://github.com/theDesConnet/AnixartJS) API.

## Стек

- **Electron** — десктопное приложение
- **Vite** — сборка фронтенда (быстро и стабильно)
- **SCSS** — стили
- **TypeScript** — типы в рендерере
- **AnixartJS** — неофициальный API Anixart (работает в main-процессе Electron)
